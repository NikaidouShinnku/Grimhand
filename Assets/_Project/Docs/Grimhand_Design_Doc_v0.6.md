**Game Design Document v0.6**  
**日期：** 2026-06-05  
**状态：** 与当前代码实现对齐（以 Unity 项目 `Assets/_Project` 为准）

> v0.5 中关于「弹反挂 tag、下次受击触发」等描述已作废。本文档反映 2026 年 5–6 月实装机制。

---

## 1. 项目概述

### 1.1 一句话定位

**3v3 回合制卡牌 + Roguelike PvE**：玩家控制三名角色组成小队，在远征地图中选择路线、收集遗物与卡牌，通过站位与速度博弈击败敌人。

### 1.2 设计支柱

| 支柱 | 说明 |
|------|------|
| 小队协同 | 三名角色各有牌组，共享团队能量与抽牌堆 |
| 站位博弈 | 前/中/后排影响输出与承伤；死亡后有效阵型前移 |
| 速度可见 | 规划阶段可预览本回合完整行动顺序（含应对插队） |
| Roguelike 远征 | 路线选择、事件、祭坛、商人、战后奖励；HP/等级跨场保留 |
| 信息博弈 | 敌方多牌时部分意图隐藏，轮到结算时才揭示 |

### 1.3 目标平台与受众

- **平台：** PC（Steam）
- **单局时长：** PvE 远征约 30–60 分钟（10 层地图）
- **受众：** 喜欢 Slay the Spire / 小队 RPG / 站位卡牌 的玩家

## 2. 战斗系统

### 2.1 战斗结构

**默认 3v3**（可配置遭遇模板）。每边最多三个物理槽位：前排 / 中排 / 后排。

### 2.2 回合阶段

```
抽牌(Draw) → 规划(Planning) → 速度结算(SpeedResolve) → 回合结束(EndOfTurn) → 循环
                                                              ↓
                                                         战斗结束(BattleEnd)
```

| 阶段 | 玩家能做什么 | 系统行为 |
|------|--------------|----------|
| 抽牌 | 观看 | 回能量、回合开始状态 tick、抽 5 张牌；敌方同步抽牌 |
| 规划 | 选牌、指定目标、使用消耗品（每场 1 次） | 敌方 AI 生成本回合出牌计划与**意图** |
| 速度结算 | 观看演出 | 按速度顺序逐张结算；应对可插队；动画播放 |
| 回合结束 | — | 护甲清零、双方手牌弃掉、状态持续时间 -1、回合数 +1 |

### 2.3 能量

| 项 | 数值 |
|----|------|
| 能量上限 | 8（可被遗物 / 事件加成） |
| 首回合 | 回满至上限 |
| 之后每回合 | 当前 +4，不超过上限 |
| 选牌 | 规划时即时扣费；取消选择退还 |

### 2.4 牌堆与手牌

| 项 | 数值 |
|----|------|
| 每回合抽牌 | 5 |
| 手牌上限 | 8（溢出直接进弃牌堆） |
| 牌组归属 | 每名角色有 `OwnerCharacterId` 标记的牌，汇入**队伍共享**抽/弃牌堆 |
| 洗回 | 抽牌堆空时，弃牌堆洗回（敌方无主 / 无在场主人的牌不参与洗回） |

### 2.5 速度结算

1. 按角色**有效速度**（基础速度 + 状态修正）分组。
2. 同速组内随机洗牌。
3. 多轮队列：每轮每个存活角色最多出一张已计划牌，直到双方队列空。
4. **应对攻击**可在敌方攻击牌结算前插队（见 §2.8）。

规划阶段选牌后，UI 显示 **【行动顺序】** 预览；提交后至下回合规划开始前，演出期间面板**冻结为本回合快照**，不提前显示下一回合敌方意图。

### 2.6 阵型与站位

#### 物理槽位 vs 有效槽位

- **物理槽位**：角色配置中的 Front / Middle / Back，用于 UI 站位与换位技能。
- **有效槽位**：仅统计存活单位，按物理槽位排序后依次占据「有效前/中/后排」。前排死亡后，中排变为有效前排。

#### 伤害倍率（按有效槽位）

| 槽位 | 输出倍率 | 承伤倍率 |
|------|----------|----------|
| 前排 | ×0.7 | ×0.7 |
| 中排 | ×1.15 | ×0.85 |
| 后排 | ×1.3 | ×1.0 |

#### 默认目标

嘲讽持有者 → 否则敌方**有效前排**（存活排序第一）。

#### 在场出牌权（Field-Active）

- 每个物理槽位仅**列表中第一个存活单位**视为「在场展示」并可出牌。
- 开战时锁定 `BattleStartFieldRoster`；同槽替补单位**不会**在队友死后自动获得出牌权（死后补位机制暂未实现）。
- 仅在场单位的牌进入抽牌循环；隐藏单位的手牌会被跳过。

### 2.7 胜负

任一方三名角色全部 HP≤0 → 对方胜利。

### 2.8 应对攻击（Respond）

> 关键词：**应对攻击** — 当该角色受到攻击时，提前于攻击将此应对的效果生效。

#### 识别

- 卡牌含 `parry` 关键词，或含带触发条件的动作。

#### 流程

1. 玩家规划阶段打出应对卡（消耗能量，进入本回合计划）。
2. 速度结算时，当轮到**首张**「会攻击该应对者」的敌方牌时：
   - 按玩家出牌队列顺序，依次结算所有匹配的应对卡；
   - 再结算该敌方攻击牌。
3. 多张应对可叠在同一触发牌上（如：减伤 → 再减伤 → 再反击 → 再结算 AOE）。

#### 无匹配

若无敌方牌满足触发条件，应对卡仍消耗，但条件效果不生效（仅执行无条件段）。

#### 典型效果

- **减伤**：按所受伤害百分比获得护甲层，在该敌方牌造成伤害时削减 HP 伤害。
- **反击**：按预估 incoming 威力百分比立即反击攻击者；若反击致死，跳过该敌方牌的伤害段。

#### 与旧版区别

- ~~出牌挂 ActiveParry，下次受击触发~~ **已废弃**
- ~~依赖 LastAction 即时反击~~ **已废弃**（非应对路径下 LastAction 条件恒 false）

## 3. 卡牌系统

### 3.1 卡牌类型

| 类型 | 说明 |
|------|------|
| Attack | 伤害类 |
| Defense | 护甲 / 应对类 |
| Status | 状态 / 辅助类 |

### 3.2 目标与射程

- **需点选**：对敌/对友的单体伤害、治疗、护甲、状态（非 Self）。
- **自动**：Self、按槽位、全体等。
- **Reach**：Any / FrontAndMiddle（默认近战）/ BackOnly。
- 关键词约束：`melee`（前中排）、`snipe`（任意后排）、`far_shot`（可打后排但衰减）、`slot`（按槽位自动选）。

### 3.3 关键词图鉴

| ID | 显示名 | 说明 |
|----|--------|------|
| block | 护甲 | 优先吸收生命伤害；回合结束清零 |
| parry | **应对攻击** | 当该角色受到攻击时，提前于攻击将此应对的效果生效 |
| poison | 中毒 | 回合开始每层 1 伤害 |
| slow | 减速 | 降低速度，影响同速顺序 |
| melee | 近战 | 只能指定敌方前排或中排 |
| snipe | 狙击 | 可指定任意敌方单位 |
| pierce | 贯通 | 主目标后方溅射 |
| far_shot | 远射 | 可打后排，后排伤害降低 |
| slot | 槽位 | 按前/中/后排自动选目标 |
| exhaust | 消耗 | 打出后移出循环 |
| sacrifice | 献祭 | 自伤类；配合血祭坛遗物 |

悬停卡牌时，在牌旁弹出浮层：**粗体关键词 + 描述**（与角色属性悬停框风格一致）。

### 3.4 污染牌

- 角色死亡后，其所有牌标记为不可用（`polluted`），规划不可选，UI 显示 `[污]`。
- **复活祝福**状态：致死时恢复 25% MaxHP 并净化该角色污染牌（每场一次）。

### 3.5 敌方卡牌

- 敌人使用随机技能池：开战前从 4 种候选技能中随机 2–4 种，生成固定张数牌组。
- 敌方共享一个抽牌堆 / 手牌 / 弃牌堆。
- **意图**：规划阶段展示本回合计划出牌；≥3 张时第 2 张可能隐藏；≥4 张时第 3 张 50% 隐藏；结算轮到该牌时揭示。

## 5. 角色与成长

### 5.1 首发三人

| 角色 | 定位 |
|------|------|
| 战士 | 前排坦克；嘲讽、应对攻击、高 DEF |
| 法老 | 中排辅助；团队护甲、治疗、复活 |
| 恶魔 | 后排输出；献祭、吸血、AOE |

### 5.2 等级

- 等级 **1–20**；战后全队获得 XP（默认 16/场）。
- 升级公式：升到 Lv.N（N≥2）需 `(N-2)×3+8` 累计 XP。
- 升级重算 MaxHP/攻防速；远征中 HP 按增量补满差值。

### 5.3 跨场保留

- 当前 HP（最低 1 带入下场）
- 等级 / XP
- 加成卡牌（奖励加入 `BonusCards`）
- 遗物列表
- 金币、消耗品栏

## 8. 远征（Roguelike）

### 8.1 地图

- 默认 **10 层**，末层 Boss。
- 每层 2–3 条路线；节点类型：战斗 / 精英 / 宝箱 / 事件 / 商人 / 祭坛 / Boss。
- 第 1 层固定战斗；3–7 层保底至少 1 商人；4–9 层保底至少 1 精英。
- 连续 2 层战斗后，下一层强制出现非战斗选项。

### 8.2 流程

```
选路线 → 战斗/事件/祭坛/商人 → 战后奖励拾取（逐项领取或放弃）→ 再选路线 → … → 通关或失败
```

### 8.3 战后奖励

每场胜利独立 roll：金币（15–25）、遗物（25%）、卡牌（25%）、消耗品（25%）。  
**原则：** 所有获得物经 RewardPickup 界面，玩家可放弃。

### 8.4 事件与祭坛

- **15 个随机事件**（神秘旅者、魔法泉水、赌徒骰子、玉匠工坊等）— 多数已实装；部分选项仍为占位消息。
- **4 类祭坛**（血 / 知识 / 灵魂 / 混沌）— 文案完整；知识/灵魂高级选项占位。

### 8.5 商人

| 服务 | 状态 |
|------|------|
| 治疗 25 金（全队 25% HP） | ✅ |
| 购买小/大药水、烟雾弹 | ✅ |
| 删牌 20 金 | ⚠️ 占位（扣金但未删牌） |
| 购随机卡 / 遗物 / 升级 | ❌ 未实现 |

### 8.6 敌人 scaling

远征第 N 场（N>1）：敌方 HP +25%/层、ATK +15%/层、DEF +5%/层（±10% 随机）。  
事件「神罚」：下一场敌方 ATK ×1.2。
