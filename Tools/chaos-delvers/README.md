# 深渊共牌 / Chaos Delvers — v0.7 观战、分级生态与三军入侵

俯视角2D本地原型，仅修改 Tools/chaos-delvers，不接入 Unity 战斗系统。

## 启动与操作

运行 node Tools/chaos-delvers/serve.cjs，打开 http://127.0.0.1:4178/。也可直接打开 index.html 离线试玩。刷新重置本局。WASD按住移动，右键寻路，左键攻击/开启目标，按住左键连续攻击；1–4选手牌，F攻击，Esc取消，M地图。

## 实时规则

- 玩家和怪物持续行动。移动以格/秒表示；攻击使用共享CD，换装与卸装继承CD，重炮至少准备2秒。近战前摇结束时检查实际距离，弹体可躲。
- 道具共用1.2秒间隔（星丝长袍0.85秒），同类效果有额外CD。建造和召唤不设次数限制，仅0.25秒施放间隔。
- 每15秒统一从公共混乱牌堆补牌：四人都存活且未满时共消耗4张。手牌上限4张；满手跳过，不扣牌、不替换、不补发。起手1张混乱牌。
- 私人核心10张，混乱20张，无构筑预算，每卡最多2份。四人共80张混乱，起手后剩76；核心保持私人所有。
- 每60秒一架核心空投：50秒预告，60秒落地，以此类推。位置公开；靠近点击开启2.5秒，从开启者自己的核心牌堆抽1张。需手牌空位和可抽核心牌。移动、攻击、出牌取消，单纯受伤不取消；争抢只奖励最先完成者。落地90秒后过期。
- 每90秒尝试生成一个限时公共事件：遗迹宝库或回响涌泉，持续45秒。靠近开启4秒获得混乱牌与金币，涌泉额外治疗20。信标公开，不揭露附近敌人与地形。
- 每45秒按地形少量刷新原生种。Boss预告8秒降临；入侵每8秒一波，共3波。怪物持续移动，攻击、治疗、折跃分别冷却。

## 战斗细则

普通剑、匕首、斧、诅咒剑和魔渊刃攻击前方2格深×3格宽，矛与冰矛为4×1，巨锤3×3。四方向按鼠标主轴确定；地面显示范围。近战可对空挥击，前摇结束以当时站位和锁定方向检查范围，支持多个敌人，但同一大型单位/共享墙体每次只受一次伤害。墙体阻挡其后的攻击，友方不会被挥砍伤及。镜片增加一格纵深。

人物旁仅显示绿色攻击冷却圆环，无底框或文字。弓箭使用连续角度瞄准线，预览与实际弹道一致，支持斜射。手牌和装备只在内容变化时重建，AI刷新与计时不会打断点击。

武器区分：匕首2秒内第三次连击追加6伤害；破障斧短暂硬直与3倍拆墙；巨锤震地击退；诅咒剑吸取30%实际伤害；冰矛冻结0.45秒；熔岩斧留下3秒灼烧地面；魔渊刃追加穿透两名目标的剑气。短弓疾速箭、法杖爆裂火球、重炮范围爆破拆墙、冰弓寒霜碎片、雷杖最多再连锁3名敌人，水域扩大跳跃范围。各自使用不同弹体、轨迹与命中特效。

新增三张抽牌控制卡（都有独立效果CD，同时遵守公共道具短间隔）：

- 混乱“命运换签”：消耗本牌立即抽一张共享混乱牌，不移动公共倒计时；CD6秒，满4张也可使用，因为先消费自身卡位。
- 混乱“迟滞封印”：全体下次补牌延后8秒，本次补牌总周期上限30秒（固定本轮截止，不会随多次施放持续后移）；CD20秒。已达上限时不消耗卡。
- 核心“催牌银铃”：全体下次补牌提前5秒，最少保留0.5秒；CD15秒。

三张有独立原创插画与收藏入口，图鉴“新藏品”可领取试玩。默认构筑也包含新道具。

所有怪物均有招式预警和独立冷却：苔团跃落、飞翼掠袭、猎犬扑咬/半血狂奔、炮台扇射、弩手后撤双连射、医师优先治疗/藤蔓、孢虫九格自爆、岩卫破墙击退、巨卫环形践踏/护甲、巢穴粘滞脉冲；五域原生种分别为种荚散射陷地、寒鳍扇射冰面、熔腹爆破火场、折跃双棱光、血线汲取与狂奔。

空壳君王轮换十字裂斩、空壳环刃、囚笼唤卫（临时墙6秒后消失）；熔核巨像轮换熔火断层、连环喷发、八向熔弹。半血后缩短招式间隔。Boss原卡仍按实体生命周期回收，技能产生的短期墙体和增援不复制原卡。

## 实体卡循环

每张卡有唯一uid、带入者、核心/混乱来源与当前位置。牌堆→手牌→装备或世界实体→对应弃牌堆→牌堆耗尽后洗牌。

即时道具结算后回收；装备替换或从详情卸下后回收；召唤物死亡、方块摧毁、持续效果结束后才回收原卡。Boss卡从预告移交Boss，死亡后回收；入侵卡在巢穴摧毁或三波结束后回收。核心卡回到原主人的私人弃牌堆。基础初始装备不凭空生成牌，场上卡不会复制入牌堆。战报会显示混乱牌的带入者。

## 保留内容与试玩范围

61张原创插画卡、五种地形和专属怪物、不规则大陆、2×2/3×3/4×4完整占位、RTS三态迷雾。探索记忆保存上次看到的地形、墙体和宝箱。友方绿、敌方红、未激怒中立黄。

本地暂停、说明、收藏、装备详情和M地图会暂停模拟。倍速同时影响所有计时。你+3名AI，尚无真实联机、永久经济或存档。对局时长和实时数值需要真人测试；保留一次早期8秒重生与按时间推进的雾潮。

## v0.7 新增规则

基础移动2.2格/秒，常规攻击CD1.5秒，各特殊武器冷却统一增加30%。死亡自动观战存活玩家，按钮或Q/E切换；使用被观战者的视野、探索记忆和装备详情，复活自动回到自己。

野生Ⅰ、召唤Ⅱ、老练Ⅲ、精英Ⅳ、首领Ⅴ在血量、伤害、移动和技能间隔上区分。开局野生苔团移动约0.73格/秒，为玩家三分之一，只做近身攻击；召唤苔团保留跃落。3分钟后生态开始出现老练怪物，6分钟后出现精英。地面单位站立时不再统一跳动。

新增盐雾海盗、烛骨亡灵、铜牙哥布林三张公共入侵卡，3秒预警后出兵，共3波，波间12秒，逐波加强。海盗火铳扇射与钩索拖拽；亡灵盾卫、复生术士与骨仆；哥布林投弹、绊索与固定连弩。营地位置公开，摧毁可停止后续增援；完成三波后清剿剩余敌人结束，90秒超时撤营。原卡随营地结束回收。每3分钟也可自然触发一场入侵。旧的巢穴卡仍为每8秒一波。


召唤阵营：默认对召唤者中立（黄条），被召唤者攻击后敌对（红条）；对其他玩家始终敌对。入侵营地、现有波次与后续波次共享对召唤者的仇恨，技能产生的子单位继承阵营和仇恨。苔团伙伴、菌伞医师明确标注【友善】，对主人保持绿条并免受其常规攻击。Boss敌对所有玩家和其他Boss，实际选敌、范围攻击与弹道均使用一致的阵营规则。
