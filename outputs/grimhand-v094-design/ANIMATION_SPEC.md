# 动作与运行时绑定提案

当前游戏的五种姿态分别绑定静态图，配合既有位移、闪烁和停留；只有Idle有逐帧列表/GIF支持。攻击三帧是额外准备的素材，**仅把PNG放进文件夹不会自动播放三帧**，也不会自动接到伤害事件。

接入建议：保持现在的位移速度和统一战斗加速逻辑。普通攻击切过头蓄力，再到前踏下劈，最后低位收势；伤害飘字/音效在命中帧出现，而不是在蓄力时出现。大斧动作不能使用普通匕首式的仅平移攻击。

- 蓄力：约0.15秒，斧头完全举过头。
- 命中：约0.10秒，前腿承重，斧刃远离原待机位置。
- 收势：约0.18秒，身体和斧刃低位，接回待机。
- 防御：用架挡姿态持续到该次应对结束，不能提前切回待机。
- 受击：身体后仰与现有受击闪白叠加，不改变伤害次数或狂怒触发次数。
- 倒地：整体高度下降，持续保留至复活或战斗结束；不可继续Idle循环。
- 延迟伤害/中毒：沿用现有事件表现，不额外播放一次斧击。
- AOE：一张牌只播放一轮完整斧击，对多个目标分别飘字，不重复消耗狂怒。

以上时长是制作初值，尚未Unity体验验收；必须使用BattlePresentationSpeed缩放，不能硬编码成忽略快进的等待。

Idle第二帧必须与第一帧相同画布、身体高度、脚底基准和持斧位置。任何缩放、左右漂移或装备变化都应退回修图，不用循环时整体抖动掩饰。现有Idle循环固定每帧0.13秒；只有两帧时可能过快，接入前要延长停留或增加真正的中间呼吸帧，不能宣称已完成平滑动画。

建议导入：Sprite、无MipMap、保留alpha、单张完整切片，PixelPerUnit与现有角色100保持一致。Point过滤与现有旧素材的Bilinear效果需要在实际显示大小并排对照，不能只看1024级大图。所有动作保持同一人物高度和脚底基点；宽画布不能导致整个人缩小。

绑定目标：CharacterVisualCatalog条目char_berserker；IdlePortrait、AttackPortrait（下劈命中）、DefensePortrait、HitPortrait、DeathPortrait、CardProfilePortrait、IdleAnimationFrames。若未扩展攻击逐帧播放，AttackPortrait至少使用可清楚看出砍出动作的命中图，不能误用蓄力图。
