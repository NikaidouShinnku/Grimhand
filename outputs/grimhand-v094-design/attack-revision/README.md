# 裂斧攻击姿态修订

用途：替换游戏中向下俯身、缺少挥斧轮廓的攻击图，不改变其他姿态、角色机制或存档。

生成方式：内置 image_gen，透明背景，现有 idle.png 为身份和风格参照、旧 attack.png 为需替换的动作参照。

制作要求：角色朝右，双手持同一斧柄，躯干扭转但不弯腰，双臂明确向右前方挥出；斧刃位于身体右侧远处、胸肩高度，而非垂在膝盖边。保持红短发、蓝眼、毛领、银甲、黑皮甲、红色开衩战裙与原有粗像素比例。1024×1024透明画布，完整人物和斧子，不添加挥击光效、背景、文字或阴影。只允许最近邻像素网格和透明画布对齐整理，不以模糊或平滑处理掩盖姿态。

Unity目标：Assets/The Grimhands Asset/characters/berserker/attack.png，保留原有.meta及其GUID；旧攻击图另存于本目录作为可恢复备份。
